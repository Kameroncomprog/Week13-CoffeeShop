# Hornet Coffee ☕

What the Program Is:
Hornet Coffee is a Java coffee shop game where users can order food and drinks, use coupons, check out, and view sales.

How to Run It: 
Open `CoffeeShopApp.java` in IntelliJ and click the green Run button (▶) next to the `main` method.

The Seven Classes:

1. MenuItem: Stores the name and price of each item.
2. Drink: Handles drink sizes and additional costs.
3. Food: Handles food items and heating costs.
4. Menu: Stores and displays the eight food and drink options.
5. Order: Keeps track of customer orders, coupons, discounts, and totals.
6. CoffeeShop: Manages the menu, completed orders, and daily sales.
7. CoffeeShopApp: Runs the game and handles the user's choices.

Something That Was Hard: 
The hardest part was creating the game loop, but I fixed it by using a while loop and a boolean variable to keep the game running until the user chooses 0.
